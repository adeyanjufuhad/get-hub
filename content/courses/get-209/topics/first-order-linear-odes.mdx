## 1. Overview

In **Stewart Chapter 9 (§9.5)**, any differential equation of the form $\frac{dy}{dx} + P(x)y = Q(x)$—even when it is impossible to separate variables—collapses into an exact Product Rule derivative the moment we multiply through by an **integrating factor** $I(x)$.

---

## 2. Key Concepts

### Standard Form & Integrating Factor $I(x)$ (Stewart §9.5)

1. Divide by any leading coefficient so the equation is strictly in **standard form**:
   $$\frac{dy}{dx} + P(x)\,y = Q(x)$$
2. Compute the **integrating factor**:
   $$I(x) = e^{\int P(x)\,dx}$$
3. Multiply both sides by $I(x)$ and collapse the left-hand side via the Product Rule:
   $$\frac{d}{dx}\bigl[I(x)\,y\bigr] = I(x)\,Q(x)$$
4. Integrate both sides (including $+C$ immediately!) and divide by $I(x)$:
   $$y(x) = \frac{1}{I(x)}\left[\int I(x)\,Q(x)\,dx + C\right]$$

## 3. Textbook Worked Examples

<StepRevealExample
  title="Stewart §9.5 Example 1 — Solving dy/dx + 3x²y = 6x² (Fig. 1)"
  problem="Solve the first-order linear differential equation $\dfrac{dy}{dx} + 3x^2 y = 6x^2$."
  steps={[
    "Identify standard-form coefficients: $P(x) = 3x^2$ and $Q(x) = 6x^2$.",
    "Compute the integrating factor: $I(x) = e^{\\int 3x^2\\,dx} = e^{x^3}$.",
    "Multiply both sides by $e^{x^3}$ and collapse via the Product Rule: $e^{x^3}\\frac{dy}{dx} + 3x^2 e^{x^3} y = 6x^2 e^{x^3} \\implies \\frac{d}{dx}\\bigl(e^{x^3} y\\bigr) = 6x^2 e^{x^3}$.",
    "Integrate both sides (using $u = x^3, du = 3x^2\\,dx$): $e^{x^3} y = \\int 6x^2 e^{x^3}\\,dx = 2e^{x^3} + C$.",
    "Divide through by $e^{x^3}$: $y = 2 + C e^{-x^3}$."
  ]}
/>

<StepRevealExample
  title="Stewart §9.5 Example 2 — Variable-Coefficient IVP x²y' + xy = 1 (Fig. 2)"
  problem="Find the solution of the initial-value problem $x^2 y' + x y = 1$ ($x > 0$), given $y(1) = 2$."
  steps={[
    "Divide both sides by $x^2$ to put the ODE into standard form: $y' + \\frac{1}{x} y = \\frac{1}{x^2}$ ($x > 0$).",
    "Compute the integrating factor: $I(x) = e^{\\int (1/x)\\,dx} = e^{\\ln x} = x$.",
    "Multiply standard form by $x$: $x y' + y = \\frac{1}{x} \\implies (x y)' = \\frac{1}{x}$.",
    "Integrate both sides: $x y = \\int \\frac{1}{x}\\,dx = \\ln x + C \\implies y = \\frac{\\ln x + C}{x}$.",
    "Apply initial condition $y(1) = 2$: $2 = \\frac{\\ln 1 + C}{1} = C$. Thus $y(x) = \\frac{\\ln x + 2}{x}$."
  ]}
/>

## 4. Common Exam Pitfalls

<Callout variant="warning" title="Two classic integrating-factor traps">
- **Forgetting to divide by $x^2$ first in Example 2:** Using $P(x) = x$ instead of $P(x) = \frac{1}{x}$ yields the wrong integrating factor $e^{x^2/2}$ and stalls the integral completely.
- **Dividing before adding $+C$:** In Example 2, $+C$ sits *inside* the numerator $\frac{\ln x + C}{x}$, NOT tacked on as $\frac{\ln x}{x} + C$!
</Callout>
